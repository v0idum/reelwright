# Examples

This directory contains small, redacted artifacts that show Reelwright's
pipeline shape without requiring Higgsfield credits or exposing local runtime
state.

- `ai-video-workflow-demo/video-plan.json` - director planning output for a
  neutral demo brief.
- `ai-video-workflow-demo/shot-manifest.json` - generation-ready planned shots
  compiled from the plan.
- `ai-video-workflow-demo/qa-report.json` - representative ffmpeg/probe
  QA output for a rendered YouTube export.

The sample files use no signed media URLs, no generated asset URLs, no secrets,
and no user-specific local paths. They are intentionally small so they can be
reviewed quickly in a public repository.
